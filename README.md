# Cosmoria — distribution

This branch holds the public distribution metadata of **Cosmoria** (Minecraft 26.2 + Fabric modpack) and of the
**Cosmoria Launcher**. It is independent of `main`, which keeps the legacy MC Challenge releases.

- `launcher/stable.json`, `launcher/dev.json`: update metadata read by the Cosmoria Launcher (signed updates only).
- Launcher installers are attached to the GitHub releases `launcher-vX.Y.Z`.

Files here are written by the Cosmoria release pipeline; please do not edit them by hand.
